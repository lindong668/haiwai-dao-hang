Gerador UUID

Atualizado em outubro de 2026Categoria: Utilidades para desenvolvedoresTestado na prática

Um UUID é um identificador de 128 bits que é único o suficiente para ser gerado em qualquer lado sem coordenação com uma autoridade central. Esta ferramenta produ-los em massa para chaves, IDs e dados de teste.

O que é

Os UUIDs resolvem um problema específico: gerar identificadores em sistemas distribuídos sem um contador central. A versão 4 usa números aleatórios, dando 122 bits aleatórios — a probabilidade de colisão é tão baixa que pode gerá-los em segurança em qualquer lado sem verificar.

A ferramenta gera UUIDs padrão RFC 4122, e normalmente oferece várias versões. Versão 4 (aleatório) é o que quase toda a gente quer. A versão 1 embute um timestamp e um endereço MAC, o que é útil quando a ordenação importa mas deixa escapar alguma informação sobre quando e onde foi criado.

As opções normalmente incluem quantidade, hifenização, chavetas e maiúsculas, e a geração acontece no seu navegador.

Como usar

  1. Vá a uuidgenerator.net.
  2. Escolha a versão — v4 (aleatória) a menos que tenha uma razão para não o fazer.
  3. Defina quantos precisa e quaisquer opções de formatação (hífenes, chavetas, maiúsculas).
  4. Clique em gerar e copie os resultados.
  5. Cole na sua seed de base de dados, ficheiro de configuração ou dados de teste.

Pontos fortes e limitações

O que funciona bem

  • Gera UUIDs conformes ao padrão instantaneamente
  • Geração em massa para popular bases de dados e dados de teste
  • As opções de formatação correspondem a diferentes convenções de armazenamento
  • Gerado localmente, sem registo
  • Sem coordenação necessária entre sistemas

Limitações

  • Os UUIDs são longos e não amigáveis para humanos em URLs ou registos
  • A v1 deixa escapar informação de timestamp e MAC se usada descuidadamente
  • UUIDs aleatórios fragmentam índices de base de dados mais do que chaves sequenciais
  • Sem garantia de ordenação

Quem deve usar

Programadores que precisam de chaves primárias, IDs de pedidos de API, dados de teste ou qualquer identificador que deva ser único sem pedir permissão a um servidor.

Perguntas frequentes

O Gerador UUID é gratuito?

Sim, a geração é gratuita sem registo, e os UUIDs são criados no seu navegador.

Que versão de UUID devo usar?

Versão 4 (aleatória) para quase tudo. A versão 1 embute um timestamp e um endereço MAC, o que tem implicações de privacidade.

Os UUIDs gerados são únicos?

Os UUIDs v4 contêm 122 bits aleatórios, tornando a probabilidade de colisão negligenciável na prática.

Posso gerar muitos de uma vez?

Sim, pode pedir um lote de UUIDs num único clique.

O que é RFC 4122?

A especificação que define o formato UUID e as versões de geração, que esta ferramenta segue.

Devo usar UUIDs como chaves primárias de base de dados?

Funcionam bem para sistemas distribuídos, mas UUIDs aleatórios fragmentam índices mais do que chaves sequenciais. Considere o compromisso para tabelas muito grandes.
