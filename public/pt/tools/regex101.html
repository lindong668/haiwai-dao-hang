Regex101

Atualizado em outubro de 2026Categoria: Utilidades para desenvolvedoresTestado na prática

As expressões regulares são notórias por serem mais difíceis de ler do que de escrever. O Regex101 resolve isso: escreva um padrão, cole texto de teste, e ele destaca as correspondências ao vivo enquanto explica cada parte do padrão em linguagem simples.

O que é

O painel de explicação é o que o distingue. Em vez de lhe dizer apenas se ocorreu uma correspondência, percorre o padrão token a token — o que \d+ faz, o que um lookahead afirma, porque um quantificador é ganancioso — para que possa perceber porque um padrão se comporta como se comporta em vez de adivinhar.

Suporta múltiplos motores: PCRE (PHP), JavaScript, Python, Go e outros. Isto importa porque a sintaxe regex difere genuinamente entre linguagens, e um padrão que funciona em JavaScript pode falhar em Go.

Funcionalidades adicionais incluem um depurador que mostra os passos de correspondência, uma biblioteca de referência rápida, geração de código e padrões guardados se se registar.

Como usar

  1. Ir para regex101.com
  2. Selecione a variante (motor) que corresponde à sua linguagem alvo.
  3. Escreva o seu padrão no campo de expressão regular.
  4. Cole texto de amostra na área de string de teste e veja as correspondências destacarem-se ao vivo.
  5. Leia o painel de explicação para perceber cada parte, ou abra o depurador para ver os passos de correspondência.
  6. Copie o snippet de código gerado para a sua linguagem quando funcionar.

Pontos fortes e limitações

O que funciona bem

  • O painel de explicação torna padrões opacos compreensíveis
  • Múltiplos motores evitam erros de incompatibilidade de variante
  • O destaque ao vivo mostra exatamente o que correspondeu
  • O depurador revela retrocesso catastrófico e problemas de desempenho
  • Gera trechos de código prontos para uso

Limitações

  • Pode sobrecarregar iniciantes com o seu número de painéis
  • A explicação assume algum vocabulário de regex
  • Os padrões guardados exigem uma conta
  • Padrões muito complexos em entradas enormes podem ser lentos

Quem deve usar

Programadores a escrever ou depurar padrões, analistas de dados a limpar texto, e qualquer pessoa que tenha herdado uma regex que ninguém entende e precise de descobrir o que faz.

Perguntas frequentes

O Regex101 é gratuito?

Sim, o testador, a explicação e o depurador são gratuitos sem registo. Uma conta permite-lhe guardar padrões.

Quais motores regex suporta?

Vários, incluindo PCRE, JavaScript, Python e Go — selecione o que corresponde à sua linguagem alvo.

Porque é que a minha regex funciona aqui mas não no meu código?

Quase sempre uma incompatibilidade de motor. Selecione a variante que a sua linguagem realmente usa antes de testar.

O que é o painel de explicação?

Uma análise que percorre cada token do seu padrão em linguagem simples, mostrando o que corresponde e porquê.

Pode ajudar com regexes lentas?

Sim, o depurador mostra os passos de correspondência e torna visível o retrocesso excessivo.

Posso guardar os meus padrões?

Sim, com uma conta gratuita pode guardar e partilhar padrões.
