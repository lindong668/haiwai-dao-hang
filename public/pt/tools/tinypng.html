TinyPNG

Atualizado em outubro de 2026Categoria: Imagem & MídiaTestado na prática

O TinyPNG é a ferramenta a que a maioria dos programadores web recorre quando uma página falha uma auditoria de velocidade. Largue as suas imagens e ele devolve versões que são normalmente 50–70% menores, com uma diferença que a maioria das pessoas não consegue ver.

O que é

A técnica chama-se quantização: em vez de desfocar pixels como faz uma regravação JPEG ingénua, reduz o número de cores distintas no ficheiro e, quando possível, muda para uma codificação mais eficiente. Para PNGs com transparência usa uma abordagem baseada em paleta que preserva os canais alfa. O resultado é um ficheiro genuinamente menor, sem os artefactos borrados da compressão JPEG agressiva.

O impacto prático é grande. Uma imagem principal que tinha 1,8 MB volta com talvez 550 KB, o que melhora significativamente o tempo de carregamento da página e as pontuações Core Web Vitals — as métricas que o Google usa como sinais de classificação.

Há um nível gratuito com limite de imagens por lote, mais uma opção paga e uma API para pipelines de build automatizados.

Como usar

  1. Vá a tinypng.com
  2. Arraste até ao limite do nível gratuito de imagens de uma vez (PNG, JPEG ou WebP).
  3. Espere enquanto cada ficheiro é processado — normalmente alguns segundos cada.
  4. Verifique a percentagem de poupança reportada para cada ficheiro; descarregue individualmente ou como zip.
  5. Compare o resultado com o original a 100% de zoom antes de publicar.

Pontos fortes e limitações

O que funciona bem

  • Grandes reduções de tamanho com perda mínima visível de qualidade
  • Preserva a transparência PNG, que a conversão JPEG ingénua destrói
  • Sem registo necessário para a ferramenta de navegador
  • Mostra a percentagem exata de poupança por ficheiro
  • A API encaixa em builds automatizados e pipelines CI

Limitações

  • Tamanho de lote limitado no nível gratuito
  • Fotografias com gradientes suaves podem mostrar bandas
  • As poupanças variam enormemente por tipo de imagem — gráficos planos comprimem muito melhor do que fotos
  • Sem controlo deslizante de qualidade fino na ferramenta gratuita

Quem deve usar

Programadores web a otimizar a velocidade da página, designers a preparar recursos para um site, e qualquer pessoa cujo CMS ou email rejeite envios por serem demasiado grandes. É particularmente eficaz em capturas de ecrã, logótipos e gráficos de cor plana.

Perguntas frequentes

O TinyPNG reduz a qualidade da imagem?

Usa compressão com perdas, por isso tecnicamente sim — mas funciona reduzindo a paleta de cores em vez de desfocar detalhes. Para a maioria das imagens a diferença é invisível a olho nu.

Mantém a transparência?

Sim, a transparência PNG é preservada, que é uma das suas principais vantagens sobre simplesmente converter para JPEG.

Quantas imagens posso comprimir gratuitamente?

A ferramenta de navegador aceita um lote limitado por envio. A API tem uma allowance gratuita mensal; além disso é paga.

Pode comprimir WebP?

Sim, o WebP é suportado juntamente com PNG e JPEG.

Existe uma API para uso automatizado?

Sim, com bibliotecas de cliente para várias linguagens, normalmente integradas em pipelines de implantação.

Funciona em fotografias?

Sim, mas fotos de tom contínuo com céus ou gradientes às vezes apresentam bandas. Verifique essas a 100% de zoom antes de publicar.
