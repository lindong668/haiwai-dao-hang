Codificar / decodificar Base64

Atualizado em outubro de 2026Categoria: Utilidades para desenvolvedoresTestado na prática

O Base64 transforma dados binários em texto simples para que possam viajar por sistemas que só aceitam caracteres. Esta ferramenta codifica e descodifica, e converte imagens em data URIs embutíveis.

O que é

Base64 é uma forma de representar dados binários usando 64 caracteres imprimíveis. Não é encriptação — qualquer pessoa o pode descodificar instantaneamente — mas resolve um problema real de transporte: corpos de email, payloads JSON, atributos HTML e algumas APIs não conseguem transportar bytes crus, e o Base64 torna-os portáteis como texto.

O uso quotidiano mais comum é o URI de dados: codificar uma imagem pequena numa string que pode colar diretamente em HTML ou CSS, removendo um pedido HTTP extra. É ideal para ícones minúsculos mas contraproducente para imagens grandes, porque o Base64 infla o tamanho em cerca de 33% e não pode ser colocado em cache separadamente.

A ferramenta lida tanto com entrada de texto como de ficheiro, em ambas as direções.

Como usar

  1. Vá a base64encode.org.
  2. Escolha codificar ou descodificar, depois escolha entrada de texto ou ficheiro.
  3. Cole o seu texto ou selecione um ficheiro de imagem.
  4. Execute a conversão e copie o resultado.
  5. Para imagens, copie o data URI e cole-o num atributo img src ou num url() de CSS.

Pontos fortes e limitações

O que funciona bem

  • Lida com codificação tanto de texto como de ficheiro
  • Produz data URIs prontos a colar para imagens
  • Sem cadastro, resultados instantâneos
  • Funciona em ambas as direções
  • Útil para embutir ícones sem pedidos extras

Limitações

  • Base64 não é encriptação — nunca o use para esconder dados
  • Cerca de 33% de overhead de tamanho torna-o inadequado para ficheiros grandes
  • Entradas muito grandes podem ser lentas no navegador
  • Sem processamento em lote

Quem deve usar

Programadores a embutir imagens pequenas em HTML ou CSS, a depurar payloads de API, e qualquer pessoa que tenha recebido uma string Base64 e precise de ver o que está dentro dela.

Perguntas frequentes

Base64 é encriptação?

Não. É uma codificação para transporte, reversível por qualquer pessoa instantaneamente. Nunca a use para proteger dados.

Esta ferramenta é gratuita?

Sim, codificar e descodificar são gratuitos sem registo.

Quanto maior fica um ficheiro com Base64?

Cerca de 33% maior do que o binário original, que é porque é melhor reservado para recursos pequenos.

Devo embutir imagens grandes como Base64?

Não. Incha o ficheiro e impede cache separada. Use-o apenas para ícones pequenos.

Posso descodificar uma imagem a partir de uma string Base64?

Sim, a direção de descodificação restaura o ficheiro original.

O que é um data URI?

Uma string como data:image/png;base64,... que pode usar diretamente como origem de imagem em HTML ou CSS, evitando um pedido de rede extra.
