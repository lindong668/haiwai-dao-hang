TinyPNG

Actualizado en octubre de 2026Categoría: Imagen & MediosProbado en la práctica

TinyPNG es la herramienta a la que recurren la mayoría de los desarrolladores web cuando una página falla una auditoría de velocidad. Suelta tus imágenes y devuelve versiones típicamente entre un 50 y un 70 % más pequeñas, con una diferencia que casi nadie ve.

Qué es

La técnica se llama cuantización: en lugar de difuminar píxeles como hace un re-guardado JPEG ingenuo, reduce el número de colores distintos del archivo y, cuando es posible, cambia a una codificación más eficiente. Para PNG con transparencia usa un enfoque basado en paleta que conserva los canales alfa. El resultado es un archivo genuinamente más pequeño, sin los artefactos borrosos de una compresión JPEG agresiva.

El impacto práctico es grande. Una imagen principal de 1,8 MB vuelve a unos 550 KB, lo que mejora de forma significativa el tiempo de carga y las puntuaciones de Core Web Vitals, las métricas que Google usa como señales de posicionamiento.

Hay un nivel gratuito con límite de imágenes por lote, más una opción de pago y una API para flujos de compilación automatizados.

Cómo usarlo

  1. Ve a tinypng.com
  2. Arrastra hasta el límite del nivel gratuito de imágenes a la vez (PNG, JPEG o WebP).
  3. Espera mientras se procesa cada archivo: normalmente unos segundos cada uno.
  4. Comprueba el porcentaje de ahorro indicado para cada archivo; descarga individualmente o en un zip.
  5. Compara el resultado con el original al 100 % de zoom antes de publicar.

Puntos fuertes y limitaciones

Lo que funciona bien

  • Grandes reducciones de tamaño con pérdida de calidad mínima visible
  • Conserva la transparencia PNG, que una conversión JPEG ingenua destruye
  • No hace falta registro para la herramienta de navegador
  • Muestra el porcentaje de ahorro exacto por archivo
  • La API encaja en flujos de compilación e integración continua automatizados

Limitaciones

  • Tamaño de lote limitado en el nivel gratuito
  • Las fotografías con degradados suaves pueden mostrar bandas
  • El ahorro varía enormemente según el tipo de imagen: los gráficos planos se comprimen mucho mejor que las fotos
  • Sin deslizador de calidad detallado en la herramienta gratuita

¿Quién debería usarlo?

Desarrolladores web que optimizan la velocidad de carga, diseñadores que preparan recursos para un sitio y cualquiera cuyo CMS o correo rechaza archivos por ser demasiado grandes. Es especialmente eficaz con capturas de pantalla, logotipos y gráficos de color plano.

Preguntas frecuentes

¿TinyPNG reduce la calidad de la imagen?

Usa compresión con pérdida, así que técnicamente sí, pero funciona reduciendo la paleta de colores en lugar de difuminar el detalle. En la mayoría de las imágenes la diferencia es invisible a simple vista.

¿Conserva la transparencia?

Sí, se conserva la transparencia PNG, que es una de sus principales ventajas frente a convertir simplemente a JPEG.

¿Cuántas imágenes puedo comprimir gratis?

La herramienta de navegador acepta un lote limitado por subida. La API tiene una asignación gratuita mensual; más allá de eso es de pago.

¿Puede comprimir WebP?

Sí, WebP es compatible junto con PNG y JPEG.

¿Hay una API para uso automatizado?

Sí, con bibliotecas de cliente para varios lenguajes, que suelen integrarse en los pipelines de despliegue.

¿Funciona con fotografías?

Sí, pero las fotos de tono continuo con cielos o degradados a veces muestran bandas. Revísalas al 100 % de zoom antes de publicar.
