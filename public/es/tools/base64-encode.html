Codificar / decodificar Base64

Actualizado en octubre de 2026Categoría: Utilidades para desarrolladoresProbado en la práctica

Base64 convierte datos binarios en texto plano para que puedan viajar por sistemas que solo aceptan caracteres. Esta herramienta los codifica y decodifica, y convierte imágenes en data URI incrustables.

Qué es

Base64 es una forma de representar datos binarios usando 64 caracteres imprimibles. No es cifrado: cualquiera puede decodificarlo al instante, pero resuelve un problema real de transporte: los cuerpos de correo, las cargas JSON, los atributos HTML y algunas API no pueden transportar bytes en crudo, y Base64 los hace portables como texto.

El uso cotidiano más común es el URI de datos: codificar una imagen pequeña en una cadena que puedas pegar directamente en HTML o CSS, eliminando una petición HTTP extra. Es ideal para iconos diminutos pero contraproducente para imágenes grandes, porque Base64 infla el tamaño en torno a un 33 % y no puede cachearse por separado.

La herramienta admite entrada de texto y de archivos, en ambos sentidos.

Cómo usarlo

  1. Ve a base64encode.org.
  2. Elige codificar o decodificar y luego selecciona entrada de texto o de archivo.
  3. Pega tu texto o selecciona un archivo de imagen.
  4. Ejecuta la conversión y copia la salida.
  5. Para imágenes, copia el data URI y pégalo en un atributo img src o en url() de CSS.

Puntos fuertes y limitaciones

Lo que funciona bien

  • Maneja codificación de texto y de archivos
  • Produce data URI listos para pegar de imágenes
  • Sin registro, resultados instantáneos
  • Funciona en ambos sentidos
  • Útil para incrustar iconos sin peticiones adicionales

Limitaciones

  • Base64 no es cifrado: nunca lo uses para ocultar datos
  • El sobrecoste de tamaño de alrededor del 33 % la hace inadecuada para archivos grandes
  • Las entradas muy grandes pueden ser lentas en el navegador
  • Sin procesamiento por lotes

¿Quién debería usarlo?

Desarrolladores que incrustan imágenes pequeñas en HTML o CSS, quienes depuran cargas de API y cualquiera que haya recibido una cadena Base64 y necesite ver qué contiene.

Preguntas frecuentes

¿Base64 es cifrado?

No. Es una codificación para transporte, reversible al instante por cualquiera. Nunca la uses para proteger datos.

¿Esta herramienta es gratis?

Sí, codificar y decodificar es gratuito sin registro.

¿Cuánto aumenta Base64 el tamaño de un archivo?

Aproximadamente un 33 % más grande que el binario original, por lo que conviene reservarla para recursos pequeños.

¿Debería incrustar imágenes grandes como Base64?

No. Infla el archivo e impide el cacheo por separado. Úsalo solo para iconos pequeños.

¿Puedo decodificar una imagen a partir de una cadena Base64?

Sí, la dirección de decodificación restaura el archivo original.

¿Qué es un data URI?

Una cadena como data:image/png;base64,... que puedes usar directamente como origen de imagen en HTML o CSS, evitando una petición de red adicional.
