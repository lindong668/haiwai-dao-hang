What You Actually Need你到底需要什么

Before comparing tools it helps to separate the jobs, because they place very different demands on a service:对比之前，先把要干的活分开，因为它们对服务的要求差别很大：

  • Restructuring — merge, split, rotate, extract, reorder结构调整 —— 合并、拆分、旋转、提取、重排
  • Size reduction — compress enough to email or upload压缩体积 —— 压到能发邮件或上传
  • Conversion — PDF to Word, Excel, PowerPoint, images, or the reverse格式转换 —— PDF 转 Word、Excel、PowerPoint、图片，或反过来
  • Security — add or remove a password, redact content安全处理 —— 加密码、去密码、涂黑敏感内容
  • Annotation — highlight, comment, sign批注签名 —— 高亮、评论、签字

All three tools cover most of this. The differences are in how much they let you do before asking for money, and what happens to your file in the meantime.这三款基本都能覆盖以上需求。差别在于：它们在收钱之前允许你做多少，以及这期间你的文件被怎么处理。

SmallpdfSmallpdf

Smallpdf has the most polished interface of the three, and for a first-time user that counts for a lot. Every tool is a single drop zone, results arrive quickly, and PDF-to-Word conversion preserves formatting well.Smallpdf 在三者里界面最精致，对第一次用的人来说这一点很重要。每个工具就是一个拖拽区，出结果很快，PDF 转 Word 的排版还原度也不错。

The constraint is the free tier: a limited number of tasks per day and caps on file size. That is fine if you handle a PDF occasionally, frustrating if you process them regularly. Paid plans remove the limits.限制在免费额度：每天任务次数有限，文件大小也有上限。偶尔处理一个 PDF 没问题，经常处理就会觉得碍事。付费方案可以去掉这些限制。

IlovepdfiLovePDF

iLovePDF offers the widest tool list and keeps most of it free without registration. Beyond the standard merge/split/compress set it handles page numbers, watermarks, OCR, unlocking and protection.iLovePDF 工具列表最长，而且大部分免注册就能免费使用。除了常规的合并/拆分/压缩，它还支持加页码、加水印、OCR、解除密码和加密保护。

The important nuance is that limits are per tool. Office-format conversion typically carries a lower size cap than merging or editing, so a large file may fail on one task and succeed on another.关键细节在于：限制是按工具分别计算的。转 Office 格式通常比合并或编辑的体积上限更低，所以同一个大文件可能在这件事上失败、在那件事上成功。

Its desktop version is worth installing if you handle PDFs often, since it processes locally.如果你经常处理 PDF，它的桌面版值得装一个，因为它在本地处理。

Pdf24PDF24

PDF24 is the least glamorous and, for many people, the most useful. There is no registration, no watermark, and — unusually — no meaningful task limit. The web interface looks dated but does everything the others do.PDF24 最不起眼，但对很多人来说最有用。不用注册、没有水印，而且 —— 这点很罕见 —— 基本没有任务次数限制。网页界面看着有点旧，但另外两个能做的它都能做。

Its real advantage is the desktop application, which runs fully offline on Windows. For contracts, financial documents, medical records or anything else you would rather not upload, this is the strongest option of the three.它真正的优势是桌面应用，在 Windows 上完全离线运行。处理合同、财务文件、病历，或者任何你不想上传的东西，它是三者里最强的选择。

If you have ever been stopped mid-task by a "you have reached your daily limit" message, PDF24 is the answer.如果你曾经被一句「您已达到今日上限」打断过手头的活，PDF24 就是答案。

Getting Better Results把结果做得更好

  • Compress after merging, not before. Compressing each file then merging produces a larger result than merging then compressing once.先合并再压缩，别反过来。 逐个压缩再合并，结果体积比合并后一次性压缩更大。
  • Convert from the original document where possible. Word to PDF produces far better results than PDF to Word to PDF.尽量从原始文档转换。 Word 转 PDF 的效果，远好于 PDF 转 Word 再转 PDF。
  • Check OCR output. Scanned documents converted without OCR look correct but contain no selectable text.检查 OCR 结果。 扫描件不做 OCR 就转换，看起来正常，但里面没有可选中的文字。
  • Flatten before sharing externally. Removing form fields and annotations prevents accidental edits by recipients.对外分享前先压平。 去掉表单域和批注，防止接收方误改。
  • Remove metadata. PDFs often carry author names, software versions and edit history you may not want to share.清掉元数据。 PDF 里常常带着作者名、软件版本和编辑记录，这些你可能并不想让人看到。

Frequently Asked Questions常见问题

Which free PDF tool has no limits?哪个免费 PDF 工具没有限制？

PDF24 has no meaningful task limits on its free web tools and also offers a fully offline desktop application.PDF24 的免费网页工具基本没有任务限制，另外还提供完全离线的桌面应用。

Do I need to register to use these tools?用这些工具需要注册吗？

No. All three work without registration for basic tasks, though limits apply.不需要。三者的基础功能都不用注册，只是各有额度限制。

Are my files uploaded when I use online PDF tools?用在线 PDF 工具时我的文件会被上传吗？

Yes, all three upload files for processing on their web versions. Install the desktop application if confidentiality matters.会。三者的网页版都要上传文件来处理。如果在意保密，就装桌面应用。

Which is best for converting PDF to Word?PDF 转 Word 哪个最好？

Smallpdf generally produces the best formatting fidelity, though results depend on how complex the original layout is.Smallpdf 的排版还原度通常最好，不过具体效果取决于原文件的版式有多复杂。

File size caps vary by tool and by task. Office-format conversion is usually capped lower than merging or editing.体积上限因工具、因任务而异。转 Office 格式的上限通常比合并或编辑更低。

Can I compress a PDF enough to email?能把 PDF 压到可以发邮件吗？
