Photopea

Photopea is the closest thing to Photoshop that runs entirely inside a browser tab. You get the familiar workspace — toolbar on the left, layers panel on the right, and keyboard shortcuts that match Photoshop almost one-to-one. If you have ever used PS, you already know how to use this.Photopea 是最接近 Photoshop 的工具，而且完全跑在浏览器标签页里。你会看到熟悉的工作区——左侧工具栏、右侧图层面板，快捷键也几乎与 Photoshop 一一对应。只要你用过 PS，就已经会用这个了。

What It Is这是什么

What makes Photopea stand out among free online image editors is format support. It reads and writes PSD, XD, Sketch, Figma, AI, EPS, PDF and RAW files, so you can open a design file sent by a colleague on a machine that has no design software installed at all.Photopea 在免费在线图片编辑器中脱颖而出的关键是格式支持。它能读写 PSD、XD、Sketch、Figma、AI、EPS、PDF 和 RAW 文件，所以即使在一台完全没装设计软件的电脑上，你也能打开同事发来的设计稿。

It is a real editor, not a simplified toy. Layers, masks, adjustment layers, smart objects, blend modes, the pen tool, vector shapes and a wide filter library are all present and behave as you would expect. Text remains editable if the font is available or substituted sensibly.它是真正的编辑器，不是简化版玩具。图层、蒙版、调整图层、智能对象、混合模式、钢笔工具、矢量形状和庞大的滤镜库一应俱全，行为也都符合预期。只要字体可用或替换得当，文字仍可编辑。

Processing happens locally in your browser — your files are not uploaded to a server. That makes it viable for confidential material such as contracts, ID scans or unreleased client artwork.处理完全在你的浏览器本地完成——文件不会上传到服务器。这意味着它可以用于处理合同、证件扫描件或未发布的客户稿这类机密材料。

How To Use It怎么用

  1. Go to photopea.com打开 photopea.com — no account or installation needed.打开 photopea.com——无需账号，也无需安装。
  2. Open a file from your computer, or drag it straight onto the canvas. You can also import from Google Drive, Dropbox or OneDrive.从电脑打开文件，或直接拖到画布上。也可以从 Google Drive、Dropbox 或 OneDrive 导入。
  3. Edit as you would in Photoshop: layers, masks, adjustment layers, pen tool, smart objects and filters all work.像在 Photoshop 里一样编辑：图层、蒙版、调整图层、钢笔工具、智能对象和滤镜都能用。
  4. Choose File → Export As to save as PSD, PNG, JPG, SVG, PDF or another supported format.选择 File → Export As，可保存为 PSD、PNG、JPG、SVG、PDF 或其他支持的格式。
  5. Use File → Save As → PSD if you need to hand a layered file back to a colleague.如果需要把带图层的文件交还给同事，用 File → Save As → PSD。
tip实用提示 Photopea 支持大部分 Photoshop 快捷键，肌肉记忆可以直接迁移。试试 Ctrl+J 复制图层、Ctrl+T 自由变换、Ctrl+Shift+E 合并可见图层。在视图里打开「吸附到图层」，对齐会省事很多。

Strengths And Limitations优点与不足

What works well好用的地方

  • Full layer, mask and smart-object support, not a simplified editor完整支持图层、蒙版和智能对象，不是简化版编辑器
  • Files stay on your machine — safe for contracts, IDs and private artwork文件留在你的电脑上——处理合同、证件和私人稿件都安全
  • Opens formats that normally require paid software, on any computer在任何电脑上都能打开通常需要付费软件才能打开的格式
  • Photoshop shortcuts work, so there is almost no learning curvePhotoshop 快捷键通用，几乎没有学习成本
  • No watermark and no export quota无水印，也没有导出次数限制

Limitations不足之处

  • Interface ads around the edges can distract on smaller screens界面边缘的广告在小屏上会分散注意力
  • Heavy 3D features and some advanced filters are weaker than desktop Photoshop重度 3D 功能和部分高级滤镜弱于桌面版 Photoshop
  • Very large multi-hundred-megabyte PSD files can strain browser memory几百 MB 的超大 PSD 文件可能吃紧浏览器内存
  • No cloud sync or version history没有云同步，也没有版本历史

Who Should Use It适合谁用

Designers who need to fix a file on the spot, students without a Photoshop licence, office workers who occasionally receive PSD files, and anyone handling sensitive images that should never leave their device.需要临时改文件的设计师、没有 Photoshop 授权的学生、偶尔收到 PSD 文件的上班族，以及任何处理「绝不能离开设备」的敏感图片的人。

Frequently Asked Questions常见问题

Is Photopea really free?Photopea 真的免费吗？

Yes. The core editor is free with no registration. There are ads around the interface, and a paid option removes them, but editing and exporting carry no watermark and no quota.是的。核心编辑器免费且无需注册。界面周围有广告，付费可去除，但编辑和导出没有水印，也没有次数限制。

Does it upload my images to a server?它会把我的图片上传到服务器吗？

No. Processing happens locally in your browser, so files never leave your machine — which is why it is suitable for confidential documents.不会。处理在你的浏览器本地完成，文件永远不会离开你的电脑——这正是它适合处理机密文档的原因。

Can it open PSD files with layers intact?打开 PSD 能保留图层吗？

Yes. PSD files open with their layer structure, masks, text layers and blend modes preserved, and you can re-export as PSD.可以。PSD 文件打开后会保留图层结构、蒙版、文字图层和混合模式，你还可以重新导出为 PSD。

Do Photoshop keyboard shortcuts work?Photoshop 的快捷键能用吗？

Most of them do — Ctrl+J, Ctrl+T, Ctrl+Alt+Shift+E and many others behave as they do in Photoshop.大部分通用——Ctrl+J、Ctrl+T、Ctrl+Alt+Shift+E 等许多快捷键的表现都与 Photoshop 一致。

Does it work on mobile?手机能用吗？

It loads on tablets and phones, but the interface is designed for a mouse and keyboard. Desktop or a large tablet is the practical choice.它在平板和手机上也能打开，但界面是为鼠标和键盘设计的。实际使用还是选台式机或大屏平板。
