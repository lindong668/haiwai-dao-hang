Photopea

Updated Oct 2026Category: Image & MediaHands-on tested

Photopea is the closest thing to Photoshop that runs entirely inside a browser tab. You get the familiar workspace — toolbar on the left, layers panel on the right, and keyboard shortcuts that match Photoshop almost one-to-one. If you have ever used PS, you already know how to use this.

What It Is

What makes Photopea stand out among free online image editors is format support. It reads and writes PSD, XD, Sketch, Figma, AI, EPS, PDF and RAW files, so you can open a design file sent by a colleague on a machine that has no design software installed at all.

It is a real editor, not a simplified toy. Layers, masks, adjustment layers, smart objects, blend modes, the pen tool, vector shapes and a wide filter library are all present and behave as you would expect. Text remains editable if the font is available or substituted sensibly.

Processing happens locally in your browser — your files are not uploaded to a server. That makes it viable for confidential material such as contracts, ID scans or unreleased client artwork.

How To Use It

  1. Go to photopea.com — no account or installation needed.
  2. Open a file from your computer, or drag it straight onto the canvas. You can also import from Google Drive, Dropbox or OneDrive.
  3. Edit as you would in Photoshop: layers, masks, adjustment layers, pen tool, smart objects and filters all work.
  4. Choose File → Export As to save as PSD, PNG, JPG, SVG, PDF or another supported format.
  5. Use File → Save As → PSD if you need to hand a layered file back to a colleague.

Strengths And Limitations

What works well

  • Full layer, mask and smart-object support, not a simplified editor
  • Files stay on your machine — safe for contracts, IDs and private artwork
  • Opens formats that normally require paid software, on any computer
  • Photoshop shortcuts work, so there is almost no learning curve
  • No watermark and no export quota

Limitations

  • Interface ads around the edges can distract on smaller screens
  • Heavy 3D features and some advanced filters are weaker than desktop Photoshop
  • Very large multi-hundred-megabyte PSD files can strain browser memory
  • No cloud sync or version history

Who Should Use It

Designers who need to fix a file on the spot, students without a Photoshop licence, office workers who occasionally receive PSD files, and anyone handling sensitive images that should never leave their device.

Frequently Asked Questions

Is Photopea really free?

Yes. The core editor is free with no registration. There are ads around the interface, and a paid option removes them, but editing and exporting carry no watermark and no quota.

Does it upload my images to a server?

No. Processing happens locally in your browser, so files never leave your machine — which is why it is suitable for confidential documents.

Can it open PSD files with layers intact?

Yes. PSD files open with their layer structure, masks, text layers and blend modes preserved, and you can re-export as PSD.

Do Photoshop keyboard shortcuts work?

Most of them do — Ctrl+J, Ctrl+T, Ctrl+Alt+Shift+E and many others behave as they do in Photoshop.

Does it work on mobile?

It loads on tablets and phones, but the interface is designed for a mouse and keyboard. Desktop or a large tablet is the practical choice.
