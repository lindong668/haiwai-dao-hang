TinyPNG

Updated Oct 20262026年10月更新Category: Image & Media分类：图片与媒体分类：图片与媒体Hands-on tested实测收录

TinyPNG is the tool most web developers reach for when a page fails a speed audit. Drop in your images and it returns versions that are typically 50–70% smaller, with a difference most people cannot see.TinyPNG 是网页速度审核不过关时，多数前端开发者第一个想到的工具。把图片丢进去，它返回的版本通常能小 50–70%，而且大多数人根本看不出差别。

What It Is这是什么

The technique is called quantisation: instead of blurring pixels the way a naive JPEG re-save does, it reduces the number of distinct colours in the file and, where possible, switches to a more efficient encoding. For PNGs with transparency it uses a palette-based approach that preserves alpha channels. The result is a genuinely smaller file without the smeared artefacts of aggressive JPEG compression.

The practical impact is large. A hero image that was 1.8MB comes back at perhaps 550KB, which meaningfully improves page load time and Core Web Vitals scores — the metrics Google uses as ranking signals.实际影响相当大。一张 1.8MB 的首屏大图可能被压到 550KB 左右，这会明显改善页面加载时间和 Core Web Vitals 得分——而这些正是 Google 用作排名信号的指标。

There is a free tier with a per-batch image limit, plus a paid option and an API for automated build pipelines.它有免费版，但每批处理的图片数量有限；另有付费方案，以及可用于自动化构建流程的 API。

How To Use It怎么用

  1. Go to tinypng.com打开 tinypng.com
  2. Drag in up to the free-tier limit of images at once (PNG, JPEG or WebP).一次拖入不超过免费版上限的图片（PNG、JPEG 或 WebP）。
  3. Wait while each file is processed — usually a few seconds each.等待每个文件处理完成——通常每个几秒钟。
  4. Check the reported saving percentage for each file; download individually or as a zip.查看每个文件报告的压缩比例；可单独下载，也可打包成 zip 下载。
  5. Compare the result against the original at 100% zoom before publishing.发布前，把结果与原图在 100% 缩放下一一对比。

Strengths And Limitations优点与不足

What works well好用的地方

  • Large size reductions with minimal visible quality loss体积大幅缩小，肉眼几乎看不出画质损失
  • Preserves PNG transparency, which naive JPEG conversion destroys保留 PNG 透明通道，而简单转 JPEG 会把它丢掉
  • No registration needed for the browser tool浏览器工具无需注册
  • Shows exact saving percentage per file显示每个文件的精确压缩比例
  • API fits into automated build and CI pipelinesAPI 可接入自动化构建与 CI 流程

Limitations不足之处

  • Batch size limited on the free tier免费版单批数量有限
  • Photographs with smooth gradients can show banding渐变平滑的照片可能出现色带
  • Savings vary wildly by image type — flat graphics compress far better than photos压缩率因图片类型差异很大——纯色图形比照片压缩效果好得多
  • No fine-grained quality slider in the free tool免费工具没有精细的画质滑块

Who Should Use It适合谁用

Web developers optimising page speed, designers preparing assets for a site, and anyone whose CMS or email rejects uploads for being too large. It is particularly effective on screenshots, logos and flat-colour graphics.优化页面速度的前端开发者、为站点准备素材的设计师，以及因为文件太大被 CMS 或邮件拒收的人。它对截图、logo 和纯色图形尤其有效。

Frequently Asked Questions常见问题

Does TinyPNG reduce image quality?TinyPNG 会降低画质吗？

It uses lossy compression, so technically yes — but it works by reducing the colour palette rather than blurring detail. For most images the difference is invisible to the naked eye.它用的是有损压缩，所以严格来说是有损——但它的原理是减少调色板颜色，而不是把细节糊掉。对多数图片来说，肉眼完全看不出差别。

Does it keep transparency?会保留透明通道吗？

Yes, PNG transparency is preserved, which is one of its main advantages over simply converting to JPEG.会，PNG 透明通道会保留，这正是它相比「直接转 JPEG」的主要优势之一。

How many images can I compress for free?免费能压缩多少张图片？

The browser tool accepts a limited batch per upload. The API has a monthly free allowance; beyond that it is paid.浏览器工具每次上传有数量限制。API 有每月免费额度，超出则收费。

Can it compress WebP?能压缩 WebP 吗？

Yes, WebP is supported alongside PNG and JPEG.支持，除 PNG 和 JPEG 外也支持 WebP。

Is there an API for automated use?有用于自动化处理的 API 吗？

Yes, with client libraries for several languages, commonly wired into deployment pipelines.有，提供多种语言的客户端库，通常会被接入部署流程中。

Does it work on photographs?适合处理照片吗？

Yes, but continuous-tone photos with skies or gradients sometimes band. Check those at 100% zoom before publishing.基本安全，但带有天空或渐变等连续色调的照片偶尔会出现色带。这类图发布前请在 100% 缩放下检查。
