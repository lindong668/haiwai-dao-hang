JSONLint

Updated Oct 20262026年10月更新Category: Developer UtilitiesHands-on tested实测收录

JSONLint is the fastest way to find out why your JSON will not parse. Paste it in, and instead of a vague error from your application you get the specific line and character where the syntax breaks.JSONLint 是查出「JSON 为什么解析不了」最快的办法。粘贴进去，它不会像你的程序那样只给个含糊的错误，而是直接告诉你是哪一行、哪个字符处语法出问题。

What It Is这是什么

JSON syntax errors are notoriously annoying because the failure message from a parser is often useless — "unexpected token" without telling you where. JSONLint points at the exact position and usually describes what it expected instead.JSON 语法错误出了名地烦人，因为解析器给的报错常常毫无用处——只说「unexpected token」却不告诉你位置。JSONLint 会精确指出位置，并通常说明它原本期待的是什么。

It catches the mistakes that actually happen in practice: trailing commas after the last array element, single quotes instead of double, unescaped characters inside strings, comments (which JSON does not permit), and mismatched brackets.它能抓到实践中真正会犯的那些错：数组最后一个元素后面多了逗号、用了单引号而不是双引号、字符串里没转义的字符、注释（JSON 不允许），以及括号不匹配。

Once valid, you can pretty-print with proper indentation or minify to a single line for shipping. It runs in the browser with no registration.校验通过后，你可以带缩进美化输出，也可以压缩成一行用于上线。它在浏览器里运行，无需注册。

How To Use It怎么用

  1. Go to jsonlint.com打开 jsonlint.com
  2. Paste your JSON into the editor, or load it from a URL.把 JSON 粘贴进编辑器，或从网址加载。
  3. Click Validate. If it fails, read the reported line number and error description.点击 Validate。若失败，看它报的行号和错误描述。
  4. Fix the issue — trailing commas, quote style and unescaped characters are the usual culprits.修正问题——常见元凶是尾随逗号、引号写法和未转义字符。
  5. Re-validate, then copy the pretty-printed or minified output.重新校验，然后复制美化后或压缩后的输出。
tip实用提示 校验大型接口响应时，先压缩再格式化。格式化器遇到真正非法的输入会失败，但能把你从一整墙单行 JSON 里看不清的结构揭示出来。

Strengths And Limitations优点与不足

What works well好用的地方

  • Pinpoints the exact line of a syntax error精确定位语法错误的行号
  • Catches the mistakes that actually occur: trailing commas, quote style, unescaped characters能抓到实际常犯的错：尾随逗号、引号写法、未转义字符
  • Pretty-print and minify in one place美化与压缩一个地方搞定
  • No registration, works immediately无需注册，立刻可用
  • Fast even on large documents即使是大文档也很快

Limitations不足之处

  • Validation only — it does not check your JSON against a schema只做语法校验——不会对照 schema 检查你的 JSON
  • No comparison or diff between two documents不支持两份文档对比或差异查看
  • Very large files can be slow to render超大文件渲染可能变慢
  • No saved history without an account没有账号就没有历史记录

Who Should Use It适合谁用

Developers debugging API responses, anyone hand-writing config files, and students learning JSON syntax. If a JSON file refuses to load, this is the first place to paste it.调试 API 返回的开发者、手写配置文件的人，以及正在学 JSON 语法的学生。如果某个 JSON 文件死活加载不了，先粘到这里就对了。

Frequently Asked Questions常见问题

Is JSONLint free?JSONLint 免费吗？

Yes, validation and formatting are free with no registration required.是的，校验和格式化都免费，无需注册。

Does it tell me where the error is?它会告诉我错误在哪一行吗？

Yes — it reports the line and position of the syntax error along with a description of what it expected.可以——它会报出语法错误的行号、位置，并说明它原本期待什么。

What errors does it catch?它能抓到哪些错误？

Trailing commas, single quotes, unescaped characters, comments, mismatched brackets and other invalid syntax.尾随逗号、单引号、未转义字符、注释、括号不匹配以及其他非法语法。

Can it minify JSON?能压缩 JSON 吗？

Yes, it can both pretty-print with indentation and minify to a single line.可以，既能带缩进美化，也能压缩成一行。

Does it validate against a schema?能按 schema 校验吗？

No, it checks syntax only. Schema validation needs a different tool.不能，它只检查语法。Schema 校验需要别的工具。

Is my data uploaded?我的数据会被上传吗？

Validation runs in the browser, but avoid pasting sensitive credentials into any online tool as a habit.校验在浏览器里完成，但请养成习惯：不要把敏感凭证粘到任何在线工具里。
