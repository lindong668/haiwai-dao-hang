JSONLint

Updated Oct 2026Category: Developer UtilitiesHands-on tested

JSONLint is the fastest way to find out why your JSON will not parse. Paste it in, and instead of a vague error from your application you get the specific line and character where the syntax breaks.

On this pageWhat It Is How To Use It Free Plan Details Strengths And Limitations Who Should Use It FAQ

What It Is

JSON syntax errors are notoriously annoying because the failure message from a parser is often useless — "unexpected token" without telling you where. JSONLint points at the exact position and usually describes what it expected instead.

It catches the mistakes that actually happen in practice: trailing commas after the last array element, single quotes instead of double, unescaped characters inside strings, comments (which JSON does not permit), and mismatched brackets.

Once valid, you can pretty-print with proper indentation or minify to a single line for shipping. It runs in the browser with no registration.

How To Use It

  1. Go to jsonlint.com
  2. Paste your JSON into the editor, or load it from a URL.
  3. Click Validate. If it fails, read the reported line number and error description.
  4. Fix the issue — trailing commas, quote style and unescaped characters are the usual culprits.
  5. Re-validate, then copy the pretty-printed or minified output.

Strengths And Limitations

What works well

  • Pinpoints the exact line of a syntax error
  • Catches the mistakes that actually occur: trailing commas, quote style, unescaped characters
  • Pretty-print and minify in one place
  • No registration, works immediately
  • Fast even on large documents

Limitations

  • Validation only — it does not check your JSON against a schema
  • No comparison or diff between two documents
  • Very large files can be slow to render
  • No saved history without an account

Who Should Use It

Developers debugging API responses, anyone hand-writing config files, and students learning JSON syntax. If a JSON file refuses to load, this is the first place to paste it.

Frequently Asked Questions

Is JSONLint free?

Yes, validation and formatting are free with no registration required.

Does it tell me where the error is?

Yes — it reports the line and position of the syntax error along with a description of what it expected.

What errors does it catch?

Trailing commas, single quotes, unescaped characters, comments, mismatched brackets and other invalid syntax.

Can it minify JSON?

Yes, it can both pretty-print with indentation and minify to a single line.

Does it validate against a schema?

No, it checks syntax only. Schema validation needs a different tool.

Is my data uploaded?

Validation runs in the browser, but avoid pasting sensitive credentials into any online tool as a habit.
