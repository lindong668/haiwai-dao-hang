What It Is这是什么

UUIDs solve a specific problem: generating identifiers in distributed systems without a central counter. Version 4 uses random numbers, giving 122 random bits — the probability of collision is so low that you can safely generate them anywhere without checking.UUID 解决的是一个具体问题：在分布式系统中生成标识符，而不需要一个中心计数器。第 4 版使用随机数，提供 122 个随机位——碰撞概率低到你可以在任何地方放心生成，无需事先检查。

The tool generates standard RFC 4122 UUIDs, and typically offers several versions. Version 4 (random) is what almost everyone wants. Version 1 embeds a timestamp and MAC address, which is useful when sortability matters but leaks some information about when and where it was created.该工具生成符合 RFC 4122 标准的 UUID，通常提供多个版本。第 4 版（随机）几乎是所有人的选择。第 1 版内嵌时间戳和 MAC 地址，在需要可排序性时有用，但会泄露一些关于生成时间和地点的信息。

Options usually include quantity, hyphenation, braces and upper case, and generation happens in your browser.选项通常包括生成数量、是否带连字符、是否加大括号、是否大写，且生成在你的浏览器里完成。

How To Use It怎么用

  1. Go to uuidgenerator.net.
  2. Choose the version — v4 (random) unless you have a reason not to.选择版本——除非有特殊理由，否则选 v4（随机）。
  3. Set how many you need and any formatting options (hyphens, braces, upper case).设置需要的数量以及格式选项（连字符、大括号、大写）。
  4. Click generate and copy the results.点击生成并复制结果。
  5. Paste into your database seed, config file or test fixture.粘贴到数据库种子数据、配置文件或测试固件中。
tip实用提示 除非确实需要按时间排序的标识符，否则一律用 v4。v1 UUID 会嵌入时间戳和 MAC 地址，可能在公开接口里泄露你并不想暴露的信息。

Strengths And Limitations优点与不足

What works well好用的地方

  • Produces standard-compliant UUIDs instantly即时生成符合标准的 UUID
  • Bulk generation for seeding databases and test data可批量生成，用于填充数据库和测试数据
  • Formatting options match different storage conventions格式选项可适配不同的存储约定
  • Generated locally, no registration本地生成，无需注册
  • No coordination needed between systems系统之间无需协调

Limitations不足之处

  • UUIDs are long and not human-friendly in URLs or logsUUID 很长，用在 URL 或日志里对人类不友好
  • v1 leaks timestamp and MAC information if used carelesslyv1 若使用不当会泄露时间戳和 MAC 信息
  • Random UUIDs fragment database indexes more than sequential keys随机 UUID 比顺序键更容易造成数据库索引碎片
  • No guarantee of sortability不保证可排序

Who Should Use It适合谁用

Developers needing primary keys, API request IDs, test fixtures or any identifier that must be unique without asking a server for permission.需要主键、API 请求 ID、测试固件，或任何「不必请示服务器也必须唯一」的标识符的开发者。

Frequently Asked Questions常见问题

Is the UUID Generator free?UUID 生成器免费吗？

Yes, generation is free with no registration, and UUIDs are created in your browser.是的，生成免费且无需注册，UUID 在你的浏览器里创建。

What UUID version should I use?该用哪个版本的 UUID？

Version 4 (random) for almost everything. Version 1 embeds a timestamp and MAC address, which has privacy implications.几乎所有场景都用第 4 版（随机）。第 1 版内嵌时间戳和 MAC 地址，存在隐私方面的问题。

Are generated UUIDs unique?生成的 UUID 是唯一的吗？

v4 UUIDs contain 122 random bits, making collision probability negligible in practice.v4 UUID 含 122 个随机位，实际碰撞概率可以忽略不计。

Can I generate many at once?能一次生成很多个吗？

Yes, you can request a batch of UUIDs in a single click.可以，点一次就能生成一批 UUID。

What is RFC 4122?什么是 RFC 4122？

The specification defining UUID format and generation versions, which this tool follows.定义 UUID 格式与生成版本的规范，本工具遵循该规范。

Should I use UUIDs as database primary keys?适合拿 UUID 当数据库主键吗？

They work well for distributed systems, but random UUIDs fragment indexes more than sequential keys. Consider the trade-off for very large tables.它们很适合分布式系统，但随机 UUID 比顺序键更容易造成索引碎片。超大数据表要权衡这一点。
