What It Is这是什么

Casing matters more than it looks. Title case follows capitalisation rules that differ by style guide, sentence case needs proper handling of abbreviations, and programming conventions like camelCase and snake_case are tedious to produce by hand across dozens of identifiers.大小写比看上去更重要。标题式的大小写规则因风格指南而异，句式大小写需要正确处理缩写，而 camelCase、snake_case 这类编程规范要在几十个标识符上手写转换，实在繁琐。

The tool handles all of these in one place, working in the browser so your text is not uploaded. It is particularly useful when moving between naming conventions — turning a list of database column names into JavaScript variables, for example.这个工具在一个页面里搞定所有这些，并且完全在浏览器中运行，文本不会上传。当你要在不同的命名规范之间切换时它特别好用——比如把一串数据库字段名转成 JavaScript 变量名。

Additional utilities typically include alternate case, inverse case and line-based transforms.此外通常还有大小写交替、大小写反转和逐行转换等附加功能。

How To Use It怎么用

  1. Go to convertcase.net.
  2. Paste your text into the input box.把文本粘贴进输入框。
  3. Click the target case: upper, lower, title, sentence, camel, snake, kebab or others.点击目标格式：全大写、全小写、标题式、句式、camel、snake、kebab 等。
  4. Review the output — title case in particular may need a manual check against your style guide.检查输出结果——标题式尤其需要对照你的风格指南人工核对一遍。
  5. Copy the result.
tip实用提示 处理编程标识符时，先转成全小写，再转 snake_case 或 kebab-case。从大小写混杂的输入直接连续转换，经常会留下多余的大写字母。
