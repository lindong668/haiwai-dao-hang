What It Is这是什么

Most converters hide their settings. CloudConvert does the opposite — you can choose the video codec, target resolution, audio bitrate, image quality and format-specific parameters before running a job. That makes it the right choice when the defaults of a simpler tool are not good enough.多数转换器都把设置藏起来，CloudConvert 恰恰相反——在跑任务之前，你可以选择视频编码器、目标分辨率、音频码率、图片质量以及各类格式专属参数。当简单工具的默认输出不够好时，它就是正确的选择。

Coverage spans documents, spreadsheets, presentations, images, audio, video, ebooks, archives and CAD/CAM files. Cloud imports from Google Drive, Dropbox, OneDrive and S3, and an API supports automated pipelines.覆盖文档、表格、演示文稿、图片、音频、视频、电子书、压缩包以及 CAD/CAM 文件。支持从 Google Drive、Dropbox、OneDrive 和 S3 导入，还提供 API 用于自动化流程。

The free tier works on a daily allowance of conversion minutes rather than a file count, which suits occasional larger jobs less well than many small ones.免费版是按每天的「转换分钟数」额度来算，而不是按文件个数，所以它更适合大量小文件，而不是偶尔的大任务。

How To Use It怎么用

  1. Go to cloudconvert.com打开 cloudconvert.com
  2. Select the source and target formats.选择源格式与目标格式。
  3. Upload your file or import from cloud storage.上传文件，或从云存储导入。
  4. Open the options panel and set codec, resolution, bitrate or quality as needed.打开选项面板，按需设置编码器、分辨率、码率或质量。
  5. Convert and download. Watch your daily conversion-minute allowance on the free tier.转换并下载。免费版要注意每天的转换分钟额度。

Frequently Asked Questions常见问题

Is CloudConvert free?CloudConvert 免费吗？

There is a free tier with a daily allowance of conversion minutes and no registration for small jobs. Volume requires a paid plan.有免费版，每天给一定转换分钟额度，小任务无需注册。量大则需要付费套餐。

What is a conversion minute?什么是「转换分钟」？

The free allowance is measured by processing time rather than file count, so long video files use it up faster than small documents.免费额度按处理时长而非文件个数计算，所以长视频比小文档消耗得更快。

Can I control output quality?能控制输出质量吗？

Yes — codec, resolution, bitrate, quality and other format-specific settings are available before conversion.可以——转换前就能设置编码器、分辨率、码率、质量及其他格式专属参数。

Does it handle video and audio?支持视频和音频吗？

Yes, extensively, which is where its detailed options matter most.可以，支持得很全面，而这也正是它那些精细选项最有价值的地方。

Is there an API?有 API 吗？

Yes, suited to automated and bulk conversion workflows.适合，很适合自动化和批量转换的工作流。

Are files uploaded?文件会被上传吗？

Yes, processing is server-side. Avoid it for confidential material.是的，处理在服务器端完成，机密材料请勿使用。
