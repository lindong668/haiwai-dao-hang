Regex101

Updated Oct 20262026年10月更新Category: Developer UtilitiesHands-on tested实测收录

Regular expressions are notorious for being harder to read than to write. Regex101 fixes that: type a pattern, paste test text, and it highlights matches live while explaining every part of the pattern in plain English.正则表达式出了名地「写起来比读起来容易」。Regex101 就是解决这个问题的：输入模式、粘贴测试文本，它会实时高亮匹配结果，同时用大白话解释模式的每一部分。

What It Is这是什么

The explanation panel is what sets it apart. Rather than telling you only whether a match occurred, it walks through the pattern token by token — what \d+ does, what a lookahead asserts, why a quantifier is greedy — so you can understand why a pattern behaves the way it does instead of guessing.真正让它与众不同的是解释面板。它不只告诉你有没有匹配上，而是逐段拆解这个模式——\d+ 做了什么、先行断言断言了什么、为什么某个量词是贪婪的——让你理解模式为何这样运作，而不是靠猜。

It supports multiple engines: PCRE (PHP), JavaScript, Python, Go and others. This matters because regex syntax genuinely differs between languages, and a pattern that works in JavaScript may fail in Go.它支持多种引擎：PCRE（PHP）、JavaScript、Python、Go 等。这一点很重要，因为正则语法在不同语言间确实有差异，在 JavaScript 里能用的模式到了 Go 可能就失效。

Additional features include a debugger that shows the matching steps, a quick-reference library, code generation, and saved patterns if you register.其他功能还包括：展示匹配步骤的调试器、速查手册、代码生成，以及注册后可保存模式。

How To Use It怎么用

  1. Go to regex101.com打开 regex101.com
  2. Select the flavour (engine) that matches your target language.选择与你目标语言对应的 flavour（引擎）。
  3. Type your pattern in the regular expression field.在正则表达式输入框里输入你的模式。
  4. Paste sample text in the test string area and watch matches highlight live.在测试字符串区域粘贴样本文本，实时观察匹配高亮。
  5. Read the explanation panel to understand each part, or open the debugger to see the matching steps.看解释面板理解每一部分，或打开调试器查看匹配步骤。
  6. Copy the generated code snippet for your language when it works.模式可用后，复制为你的语言生成的代码片段。
tip实用提示 调试前一定要选对引擎。「在这里能跑、到生产环境就失败」的正则问题，很大一部分来自测试用一个流派、运行用另一个。

Strengths And Limitations优点与不足

What works well好用的地方

  • Explanation panel makes opaque patterns comprehensible解释面板让晦涩的模式变得可读
  • Multiple engines prevent flavour-mismatch bugs多引擎可避免 flavour 不匹配的 bug
  • Live highlighting shows exactly what matched实时高亮准确显示匹配到了什么
  • Debugger reveals catastrophic backtracking and performance issues调试器能暴露灾难性回溯和性能问题
  • Generates ready-to-use code snippets生成可直接使用的代码片段

Limitations不足之处

  • Can overwhelm beginners with its number of panels面板较多，可能让新手眼花缭乱
  • Explanation assumes some regex vocabulary解释部分默认你有一定正则词汇基础
  • Saved patterns require an account保存模式需要账号
  • Very complex patterns on huge inputs can be slow超复杂模式配超大输入时可能变慢

Who Should Use It适合谁用

Developers writing or debugging patterns, data analysts cleaning text, and anyone who has inherited a regex nobody understands and needs to work out what it does.编写或调试正则表达式的开发者、清洗文本的数据分析师，以及任何接手了一段「没人看得懂」的正则、需要搞清楚它到底干什么的人。

Frequently Asked Questions常见问题

Is Regex101 free?Regex101 免费吗？

Yes, the tester, explanation and debugger are free without registration. An account lets you save patterns.是的，测试器、解释和调试器都免费且无需注册。注册账号可保存模式。

Which regex engines does it support?支持哪些正则引擎？

Several, including PCRE, JavaScript, Python and Go — select the one matching your target language.有好几种，包括 PCRE、JavaScript、Python 和 Go——选择与你目标语言一致的那一个。

Why does my regex work here but not in my code?为什么正则在这里能跑、到我代码里就不行？

Almost always an engine mismatch. Select the flavour your language actually uses before testing.几乎总是引擎不匹配。测试前请选择你所用语言实际使用的 flavour。

What is the explanation panel?解释面板是什么？

A breakdown that walks through each token of your pattern in plain language, showing what it matches and why.一段用大白话逐段拆解你模式中每个记号的分析，说明它匹配什么、为什么。

Can it help with slow regexes?能帮忙排查跑得慢的正则吗？

Yes, the debugger shows the matching steps and makes excessive backtracking visible.可以，调试器会展示匹配步骤，让过度回溯无所遁形。

Can I save my patterns?能保存我的正则吗？

Yes, with a free account you can save and share patterns.可以，注册免费账号后就能保存和分享模式。
