Base64 Encode / Decode

Updated Oct 20262026年10月更新Category: Developer UtilitiesHands-on tested实测收录

Base64 turns binary data into plain text so it can travel through systems that only accept characters. This tool encodes and decodes it, and converts images into embeddable data URIs.Base64 把二进制数据转成纯文本，这样它就能在只接受字符的系统里传输。这个工具能做编码与解码，还能把图片转成可直接嵌入的 data URI。

What It Is这是什么

Base64 is a way of representing binary data using 64 printable characters. It is not encryption — anyone can decode it instantly — but it solves a real transport problem: email bodies, JSON payloads, HTML attributes and some APIs cannot carry raw bytes, and Base64 makes them portable as text.Base64 是一种用 64 个可打印字符表示二进制数据的方法。它不是加密——任何人都能瞬间解出来——但它解决了一个真实存在的传输问题：邮件正文、JSON 数据、HTML 属性和部分 API 都无法承载原始字节，而 Base64 让它们能以文本形式流通。

The most common everyday use is the data URI: encoding a small image into a string you can paste directly into HTML or CSS, removing an extra HTTP request. It is ideal for tiny icons but counterproductive for large images, because Base64 inflates size by roughly 33% and cannot be cached separately.

The tool handles both text and file input, in both directions.该工具支持文本与文件两种输入，且编码、解码双向都可用。

How To Use It怎么用

  1. Go to base64encode.org.
  2. Choose encode or decode, then pick text or file input.选择编码或解码，再选择文本输入或文件输入。
  3. Paste your text or select an image file.粘贴文本，或选择一张图片文件。
  4. Run the conversion and copy the output.执行转换并复制输出结果。
  5. For images, copy the data URI and paste it into an img src attribute or CSS url().如果是图片，复制生成的 data URI，粘进 img 的 src 属性或 CSS 的 url() 中。
tip实用提示 Base64 是传输编码，不是加密。千万别拿它来藏东西 —— 它一秒钟就能被解开。内嵌图片控制在几 KB 以内；把一张 500KB 的照片粘进 CSS，会让样式表急剧膨胀，还会毁掉缓存。

Frequently Asked Questions常见问题

Is Base64 encryption?Base64 是加密吗？

No. It is an encoding for transport, reversible by anyone instantly. Never use it to protect data.不是。它是一种用于传输的编码，任何人都能瞬间还原。绝不要用它来保护数据。

Is this tool free?这个工具免费吗？

Yes, encoding and decoding are free with no registration.是的，编码和解码都免费，无需注册。

How much bigger does Base64 make a file?Base64 会让文件变大多少？

About 33% larger than the original binary, which is why it is best reserved for small assets.比原始二进制大约 33%，所以它最好只用在小体积素材上。

Should I embed large images as Base64?大图片应该内嵌成 Base64 吗？

No. It bloats the file and prevents separate caching. Use it for small icons only.不建议。它会撑大文件，还会导致无法单独缓存。只用于小图标即可。

Can I decode an image back from a Base64 string?能把 Base64 字符串还原成图片吗？

Yes, the decode direction restores the original file.可以，解码方向能还原出原始文件。

What is a data URI?什么是 data URI？

A string like data:image/png;base64,... that you can use directly as an image source in HTML or CSS, avoiding an extra network request.类似 data:image/png;base64,... 这样的字符串，可以直接当作图片源用在 HTML 或 CSS 里，省掉一次额外的网络请求。
